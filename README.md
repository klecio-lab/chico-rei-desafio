# chico-rei-desafio

Desafio técnico Full-Stack (CHICO REI) — API em Laravel + SPA em Vue.js que a consome, do login ao CRUD de produtos.

## Estrutura

```
chico-rei-desafio/
├── backend/    # API Laravel (MySQL + Passport + Sail) — ver backend/README.md na entrega
├── frontend/   # SPA Vue 3 + Vite (consome a API)
└── README.md   # este arquivo (será expandido com os 6 itens do edital ao longo do desenvolvimento)
```

## Stack

| Camada   | Tecnologia (versões finais no README da entrega) |
|----------|--------------------------------------------------|
| Back-end | Laravel + MySQL + Passport (OAuth2) + Sail/Docker |
| Front-end| Vue 3 + Vite + Vue Router + Pinia + Axios          |

## Status

Scaffold inicial. Instalação, seeders, contratos da API, decisões e trade-offs serão documentados aqui conforme o desenvolvimento (itens 1–6 do edital).
